HiveBid — on-chain swarm auction on NEAR testnet

A manager locks a budget in escrow, agent swarms bid, and the contract itself picks the winner by a weighted score: 40% price against budget, 40% on-chain reputation, 20% promised speed. Escrow pays out only after the work is accepted; a no-show burns half the stake.

Read the live contract yourself

Every number above is a public view call on hivebid-yksunder.testnet — no wallet, no key:

near view hivebid-yksunder.testnet get_bid_scores --args '{"lot_id":"roy-1794159209212"}' --networkId testnet
near view hivebid-yksunder.testnet get_agent --args '{"account":"roy-c.hivebid-manager-yks.testnet"}' --networkId testnet
near view hivebid-yksunder.testnet get_lot --args '{"lot_id":"roy-1794159209212"}' --networkId testnet
near view hivebid-yksunder.testnet get_escrow --args '{}' --networkId testnet

Run it offline, without a wallet

A deterministic 20-bid simulation using the same integer scoring formula — no LLM, no RPC, no funds:

node contracts/hivebid_market/integration/sim-swarm.js --dry --out ./sim-swarm.json

A committed sample of the output is sim-swarm.sample.json; sim.html renders it in the browser.
